# Feature hand-offs

Each feature built by the agent team gets a folder here: `docs/features/<slug>/`

| File | Written by | Contents |
|---|---|---|
| `spec.md` | planner | Thesis, rules, data, validation plan, acceptance criteria, plan |
| `dev-notes.md` | developer | Files changed, decisions, anything left undone |
| `test-report.md` | tester | Acceptance criteria → PASS/FAIL with evidence, validation numbers |
| `review.md` | reviewer | Blockers / should-fix / nits, final `VERDICT:` line |
| `release.md` | deployer | Commit, PR, production smoke test, rollback steps |
